# Rise-Web

Este é um website desenvolvido como projeto acadêmico utilizando ReactJS. O objetivo é apresentar uma vitrine de produtos (camisetas, canecas e bonés), com navegação moderna e visual atrativo, simulando um e-commerce simples.

## ✨ Funcionalidades

- Página inicial com destaques de produtos
- Navegação entre menus de lançamentos, canecas e bonés
- Animações com Framer Motion para uma experiência fluida
- Estrutura pronta para autenticação e dashboard (expansível)
- Layout responsivo

## 🚀 Tecnologias Utilizadas

- [ReactJS](https://reactjs.org/)
- [Framer Motion](https://www.framer.com/motion/) (animações)
- [React Router](https://reactrouter.com/) (navegação)
- CSS Modules

## 🎨 Como Executar o Projeto

1. **Clone o repositório:**
   git clone (https://github.com/Fluq1/Rise-Web)
2. **Acesse a pasta do projeto:**
   cd rise-web
3. **Instale as dependências**
   npm install
4. **Inicie o servidor dev**
   npm start
5. **Acesse http://localhost:3000 no seu navegador**

## 🛠️ Scripts Disponíveis 
- npm start — Executa o app em modo desenvolvimento
- npm run build — Gera uma versão de produção na pasta build
